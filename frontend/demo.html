Runs on a small server

The model now runs server-side — a few million parameters, milliseconds per request. No download, no setup, always ready.

Same architecture, always

Embeddings, attention, softmax, sampling — identical math to the notebook that trained it, just running remotely instead of in your browser.

Each request is generated fresh. Nothing you type is saved or logged beyond what's needed to return a response.
